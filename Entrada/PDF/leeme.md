# PDF de clase

Aquí se guardan los PDF queresume `/resumir`.

- La forma normal es **adjuntar el PDF al chat** y escribir `/resumir`: el comando
  copia el archivo aquí con un nombre corto, sin tildes.
- También vale una ruta: `/resumir Entrada/PDF/mi-tema.pdf`.
- Un archivo por tema: `angular-servicios.pdf`, `sql-basico.pdf`…
- El nombre del archivo se anota en la sección 11 del resumen como fuente.
- Los PDF **no se publican** en el sitio: se quedan solo en esta carpeta.
